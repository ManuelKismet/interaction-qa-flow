Interaction QA Flow

Build a prepared question path, then branch from any answer when the response reveals a new question.

Privacy: this tool stores data locally in your browser. Nothing is uploaded unless you export and share a file yourself.

Flow Rules

  • Prepared questions stay in the main path.
  • Any answer can add another follow-up question.
  • Clear answers separately from deleting questions.
Help

  • Answer a question to continue, then branch from any answer if a new question appears.
  • Save JSON files to reopen or share a flow later.
  • Use Report view or Print / Save PDF when you need a read-only record.
