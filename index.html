Privacy: this tool stores data locally in your browser. Nothing is uploaded unless you export and share a file yourself.

Flow Rules

  • Shared questions collect a separate answer for each participant.
  • Participant questions appear only for the active participant.
  • Any answer can add a participant-specific follow-up question.
  • Edit or delete answer text directly in the answer field.
Help
  • Add shared questions when everyone should answer the same prompt.
  • Add participant questions when only the active participant needs that prompt.
  • Switch participants to capture separate answers against the same shared questions.
  • Use Add follow-up when an answer reveals a new participant-specific question.
  • Save recurring question sets as local templates, then export them when a team needs the same set.
  • Save JSON files to reopen or share a flow later.
  • Use Report view or Print / Save PDF when you need a read-only record.
